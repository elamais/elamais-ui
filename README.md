# elamais-ui

ELA+ design system: tokens and Vue 3 components, published as an npm package
consumed by the four apps.

- Source of truth for tokens: the generated design system (Claude Design project
  "ELA+ Design System") — plum #3D1B35, champagne #D8B99A, off-white #FAF8F5.
- Accessibility rule: champagne is decorative only; text uses the derived tones
  (#7A5A2E / #B08A4F) for AA contrast.
- Typography: Playfair Display (display) + Montserrat (body/buttons).
